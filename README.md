# Linear syzygies and linear subspaces whose lines are multisecant

This is auxiliary code for the paper [Linear syzygies and linear subspaces whose lines are multisecant](http://arxiv.org/abs/2610.12078) by Jong In Han and Sijong Kwak. The code is written in Macaulay2 (version 1.26.06). The running time of the whole code is about 2 minutes on a MacBook Pro with an M5 Pro chip.
